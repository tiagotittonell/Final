# Kit inicial Codex / Astra — El Legado del Héroe

Generado a partir de la revisión **estática** del repositorio `tiagotittonell/Final` en commit `96cfbb12643174f7d5f2cc593087eec34261fa72` (rama `main`, 2026-08-03).

## Instalación manual
Copiar el contenido de este ZIP a la **raíz** de la copia local del repo (donde están `Assets/`, `Packages/` y `ProjectSettings/`). No copiar dentro de `Assets/`. Revisar `AGENTS.md` antes de usar.

No se editó ni se instaló nada en tu cuenta de GitHub. El kit sólo agrega documentación e instrucciones Markdown; no incluye scripts ejecutables ni necesita instalar dependencias.

## Primer uso
Abrir el repositorio con Codex, pedir una auditoría de solo lectura usando el prompt de `Docs/CODEX_FIRST_AUDIT.md`. Verificar después versión efectiva de Unity con el editor local, tests y compilación antes de cualquier upgrade.

## Importante
Las skills comunitarias y el plugin Unity no vienen incorporados. La compatibilidad del plugin oficial Unity requiere Unity 6+; el repo indica 2021.3.14f1 aunque conserva log de ejecución con 6000.4.3f1.
